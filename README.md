Informe – Portafolio
¿Qué hice?

Este es mi primer proyecto web con HTML. La idea era crear una página personal donde muestro quién soy, qué hago y cómo contactarme. Fue una actividad del Módulo 1 de la materia DPW.

¿Qué secciones tiene mi página?
Mi página tiene varias partes:

Un encabezado donde puse mi nombre y una frase
Una sección sobre mí con una descripción y una foto
Mis habilidades o cosas que me interesan (como programación y ciberseguridad)
Un apartado para contacto con links a mi GitHub y correo
Un pie de página con mi nombre y año
¿Qué etiquetas HTML usé?
Usé <header>, <section>, <footer>, <ul>, <img> y <a>. Escogí esas porque nos enseñaron que son las correctas para organizar el contenido. También usé <hr> para separar visualmente cada bloque.

¿Qué parte me costó más?
Me costó entender cómo subir el codigo a Github , no es algo que haga casi, lo que si me ayudo a entender como aplicar en mi ambiente laboral.

¿Qué aprendí?
Aprendí a estructurar una página HTML sin ayuda de estilos ni plantillas. También entendí mejor cómo usar etiquetas semánticas y subir todo a GitHub. Disfruté porque siento que ya puedo empezar a hacer cosas simples.
